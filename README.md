# Kairos

Kairos blocks the apps and websites that aren't part of what you're working on, and gives you
time on them only when you ask for it with a reason.

**Latest version: 1.0.20**

- **Windows:** [Kairos-setup.exe](https://github.com/WillByro/kairos-releases/raw/main/Kairos-setup.exe)
- **Mac (Apple silicon: M1 and later):** [Kairos-macos-arm64.zip](https://github.com/WillByro/kairos-releases/raw/main/Kairos-macos-arm64.zip)
- **Mac (Intel):** [Kairos-macos-x64.zip](https://github.com/WillByro/kairos-releases/raw/main/Kairos-macos-x64.zip)

## Install on Windows

1. Download **Kairos-setup.exe** and open it.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. Kairos installs for your user account (no admin needed) and opens.

## Install on Mac

1. Download the zip for your Mac and double-click it to unzip.
2. Right-click **Kairos.app** and choose **Open**, then **Open** again. (On macOS 15 and later, if
   it's blocked, go to System Settings → Privacy & Security and click **Open Anyway**.)
3. Kairos moves itself to your Applications folder and lives in the menu bar. Allow Screen
   Recording and browser access when macOS asks; that's how it sees what's in front of you.

Then add your Anthropic API key in **Settings**. Kairos updates itself from here automatically.
